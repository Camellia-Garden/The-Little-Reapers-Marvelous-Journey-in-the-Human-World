# 游戏资源整理

本仓库按游戏名称整理本地游戏文件中提取的资源。每款游戏下再按文案、图片、音频、视频和解包记录分类。

## 目录

- `犹格索托斯的庭院/`：游戏台词、原始文本与配置、纹理、精灵切图、官方附带画集、音频和视频。
- `实习死神模拟器/`：游戏台词、原始文本与配置、纹理、精灵切图、音频和视频。
- `资源来源索引.csv`：记录各导出文件的原始来源或 Unity 对象 ID，便于追溯。
- `音频提取失败清单.csv`：音频转换时出现的问题；仅有表头表示未记录转换失败。

## 如何查找

- **文案**：优先打开 `文案` 下的 `.txt` 或 `.csv`。原始 `.bin` 文件包含剧情脚本、语言表、配置、角色动画骨骼及图集信息等，不一定是可直接阅读的文本。提取出的台词按原数据记录顺序排列，并未还原实际剧情顺序、分支或说话人。
- **图片**：按文件名识别出的 CG、背景、角色头像、界面图标分类仅供参考。无法可靠判断的文件在“其他与待识别”中；“原始纹理”和“精灵切图”可能有内容重复，纹理也可能是需要配合骨骼数据使用的图集，并非完整立绘。
- **CG**：第一款游戏的 `CG与官方画集` 来自游戏附带的图片包；文件名可识别为 CG 的提取图片也放在图片分类的 CG 文件夹。第二款游戏中未能凭文件名可靠识别的图片放在“其他与待识别”。
- **音频**：`可播放音频` 是从 FMOD `.bank` 中转换的 FLAC，按来源库和序号命名，尚未确定曲名或与游戏事件的对应关系。`FMOD音频库` 保留原始文件，部分库可能只含元数据或未识别的内容。
- **视频**：MP4 文件保留游戏内原名。
- **解包记录**：记录工具输出和未成功导出的对象，不能保证所有游戏资源已经恢复。

## 下载说明

本仓库的大型二进制资源由 Git LFS 管理。克隆后需要安装 Git LFS，并执行 `git lfs pull` 获取实际图片、音频和视频；网页下载或未安装 LFS 的环境可能只得到指针文件。
